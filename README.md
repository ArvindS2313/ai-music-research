# Research-Project-PI
Code for the project "Generating Music Using Neural Networks and Routine Planning Architectures" under the guidance of Prof. Richard Fox.

This is all the code that I used in this project.
* Web Scraping Data Collection
* GPT Playground (watch me learn transformers lol)
* Chord Generation NN
* Pre-planning (short, simple)
* Post-planning (not short, simple)
* Web App Using Flask

Later, I might make this into seperate repos, but for now, I've left it all in one.
